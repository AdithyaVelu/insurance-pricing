# Actuarial Pricing Engine

A Python-based pipeline and Frequency-Severity model designed to process auto-insurance data and calculate market-ready Gross Premiums.

## Data Source
The raw data used for this project consists of multi-table datasets containing over 540k+ rows. Because of file size constraints, the raw CSVs are excluded from this repository, but you can download the datasets directly from the [Kaggle French Motor TPL Insurance Dataset](https://www.kaggle.com/datasets/karansarpal/fremtpl2-french-motor-tpl-insurance-claims).
